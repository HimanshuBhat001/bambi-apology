# Bambi's Little Apology Corner 💗

A romantic, mobile-friendly apology website featuring the **real white dog in the supplied photo**, floating hearts, a runaway "Yes 😡" button, and a sentence-by-sentence letter.

## Run
Open `index.html` in Chrome, Safari, Edge, or Firefox. No installation or server needed. Internet is optional (Google Fonts load when online; fallback fonts work offline).

## Customize
- Edit the `apologyLines` array in `script.js` to personalize the apology.
- Change the questions and button labels in `index.html`.
- The original user-supplied dog collage is in `assets/original-bambi-photo.jpg`. The three cropped photos are in `assets/`.
- Adjust colors in the `:root` block of `style.css`.

## Behavior
1. Initial question, click Yes.
2. Second question, the angry Yes button dodges cursor/touch; click No Bambi.
3. Envelope opens; letter reveals one sentence every 2.25 seconds. The final button appears after the last sentence. Scroll inside the letter to reread.
4. Final apology screen with replay button.

No data is collected or sent anywhere by this site.
